# Rider–Waite–Smith tarot artwork

The 78 card images in this folder are local, resized derivatives of the
public-domain 1909 Rider–Waite–Smith tarot artwork distributed by
[`renanbotasse/tarot`](https://github.com/renanbotasse/tarot).

The source project is MIT licensed and identifies the card artwork as public
domain. Images are stored locally so the Lisa-phone tarot table does not rely
on a third-party image host at runtime.
