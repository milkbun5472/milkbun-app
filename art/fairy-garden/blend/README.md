# 庭院 Blender 源文件

Lisa 要求保留全部现有 `.blend` 供 Opus 继续编辑；包含早期稿、改版稿、室内外场景和人物预览。原目录结构完整保留，不代表每一稿都在当前游戏中使用。

- 直接用 Blender 打开相应文件；程序化材质和建模节点保留。
- 配套构建脚本在上一层 `art/fairy-garden/`。旧脚本里的本机 `base` 路径需指向本目录，输出请另设临时目录。
- 当前运行时以 `apps/fairy-garden/rules.js` 与 GLB 为准；不要把同名旧稿直接覆盖游戏资产。
- 此目录不参与游戏缓存指纹，不需要因源文件提交而发布新版本。
