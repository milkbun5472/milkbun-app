# 基础旅人图片对照研究

本轮只处理基础造型，不替换线上模型。Lisa 要求先认真对照原图，把一个小人做好再扩展。

`build.py` 在 Blender 中从空场景构建，不导入旧模型。参考为 1024×1536 的《Codex 图像 2026年9月20日 09_21_38.png》。建模坐标依据图上的人工轮廓标记，不能当作自动测量误差或还原率。

对照相机：正交、700 px/单位，原图 x=512 对应模型 x=0，原图 y=1387 对应脚底 z=0。正面渲染与原图保持同构图；光照为软箱摄影灯，无外加辉光。

重点检查：

- 不对称分层发束的外轮廓、遮挡关系与圆钝末端。
- 连续脸颊与下巴、眼睛高度、贴在皮肤表面的腮红。
- 连续肩袖、落在胸前的独立翻领、布料体积。
- 宽裤脚、鞋头、厚底和斜挎包大小。
- 正侧背面的体积以及光照下的表面瑕疵。

生成：`STUDY_OUT=/tmp/garden-reference-study /Applications/Blender.app/Contents/MacOS/Blender -b --python art/fairy-garden/reference-study/build.py`。

本研究尚未接入换装、身体形态键和动作，不应把离线渲染当成游戏截图。

## 立体参照

Lisa 补充侧面、背面照片后，单独导入原 GLB 作只读观察；移除贴图的白模渲染确认发束本身有层叠体积。测量时将原件身高统一为 1.707，取 z>0.99 的头部：宽 0.74166、深 0.75058，厚宽比约 1.012。新稿早期厚宽比为 0.817；据此重做头部纵深、环绕后脑的分层发束、后颈覆盖、后领与完整包带。

原件保留在原路径。独立建模脚本不导入、不抽取、不复用原 GLB 顶点或贴图；这里只记录参照测量与观察。

最终本轮几何包围盒：新稿头宽 0.7674、深 0.8018，厚宽比约 1.045；原件约 1.012。这个比值只说明整体厚度，不能代表发型细节或整体还原程度。
