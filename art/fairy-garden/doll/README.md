# 光头玩偶底模

- `source-50k.glb`：Lisa 用混元生成、减到 5 万面的原件（2026-09-24），不改动。
- `doll-blank-face.glb`：`fill_eyes.py` 处理后的空白脸，用来贴 `../faces/` 的九张表情。
  1. 先焊回 glTF 在贴图接缝处拆开的顶点（不焊的话，磨平时接缝会被扯开）；
  2. 两个眼坑按椭圆范围做拉普拉斯平滑，边缘外的原件表面固定不动；
  3. 贴图上脸正面区域的眼睛深色像素刷成肤色，避开腮红；法线贴图对应区域抹平；
  4. 去掉原件的自定义法线，按新表面重新算。
- 已知残留：原眼位还有极淡的细线，会被贴上去的眼睛盖住。贴图仍是 4K，接入手机前再降到 2K。

## 表情贴图（2026-09-24 起）

- `decal.html?face=<id>&blush=[[x,y,rx,ry],…]`：把 `../faces/faces.json` 的一张表情和椭圆腮红画成 1024² 透明图，单位是参考图像素。
- `bake_face.py`：从正面投影，把这张图合进模型自己的底色贴图。只改脸正面的贴图块，并延伸到接缝的空白边，避免漏缝。旧腮红先刷回肤色，旧眼位刷平，法线贴图对应处抹平。
- 对位（十张共用一个变换，不单独挪）：1 参考像素 = 0.00145 m，头心 (x 0, z 0.870)；腮红 (±78, 80)，半径 24×18。玩偶下半脸比参考图短，所以整体比 1:1 缩小了约一成，让嘴落在两团腮红之间。
- `doll-default.glb`、`doll-happy.glb`：默认与开心的成品；`ten-faces.png`：十张总览（默认 + 九种心情）。其余八张用同一命令即可生成。
- 默认表情取自 Lisa 的光头玩偶参考图（`../faces/reference-default-doll.png`）：一对竖椭圆眼，无嘴。

## 发型：从混元「光头玩偶戴 M02」切头发（2026-09-25）

- `hunyuan-m02-source.glb`：Lisa 用混元生成的戴 M02 的整只玩偶，原样保存。
- `fit_hair.py`：
  1. 按下半个头（下巴、脸颊、耳朵，两边都没被头发挡）对齐大小和位置；
  2. 脸正面和耳朵处按颜色删掉源模型自己的皮肤，后脑一律当头发；源模型的眼窝和贴着脸的碎片删掉；
  3. 后脑陷进我们头皮的头发推到头皮外 3 mm（前半个头不动，保留中分）；
  4. 刘海以头顶为支点往上收（`FRINGE_K`，0.74），露出眼睛，头顶和后脑不动。
- 带头发时表情整体下移：`FACE_CZ=0.85`（光头时 0.87）。
- `doll-m02.glb` / `m02-views.png`：默认表情 + M02 的成品。
