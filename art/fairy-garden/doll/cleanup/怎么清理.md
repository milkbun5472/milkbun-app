# 手动清理发型：只需要「看 → 点 → 删」

文件：`M03-清理.blend`。红色的是我挑出来的**可疑碎片**（贴着脸、耳朵的小块）。别的都锁住了，点不到，不会弄坏。

效果预览：`M03-红色碎片.png`

## 步骤

1. **打开**：用 Blender（4.2 或更新）打开 `M03-清理.blend`。若弹出「脚本/自动运行」之类的提示，直接关掉。
2. **把视角对准头**：鼠标移到中间大窗口里，按一下小键盘 `.`（或者菜单 **视图 → 框显所选**；都不行就按 `Home`）。
3. **看颜色**：按 `Z`，在弹出的圆盘里选 **材质预览**（Material Preview），红色才会显示出来。
4. **转着看**：
   - 按住 **鼠标中键** 拖动 = 转
   - **滚轮** = 放大缩小
   - 按住 `Shift` + 中键拖 = 平移
   - 触控板：两指拖动 = 转，`Shift` + 两指 = 平移，捏合 = 缩放
5. **删脏的**：用**左键**点一块红色（它会变橙色描边），觉得是多余的脏东西就按 `X` → **删除**（或 `Delete` 键）。
   - 觉得是正常头发（比如整缕的侧边头发），**不用管**，留着就行，我之后会把它变回头发颜色。
   - 删错了：`Ctrl+Z`（Mac 是 `Cmd+Z`）撤销。
6. **存盘**：`Ctrl+S`（Mac 是 `Cmd+S`），然后把 `M03-清理.blend` 发给我（放 main 的 `art/incoming/` 或者直接拖进对话）。

就这些，不用画、不用改形状。
