# 刷色：你来判断哪块是头发、哪块是皮肤

文件：`M02-刷色.blend`、`M03-刷色.blend`（一个一个来）。

- **头发色** = 保留
- **亮粉色** = 「这是皮肤」，最后会被删掉
- 耳朵和脖子附近，我先按规则猜了一遍，猜是皮肤的已经刷成粉色（见 `m03-pink.png`）。你只要**改我猜错的**。
- 玩偶本体和发底锁住了，点不到；头发没锁。

## 第一次打开（只做一次）

1. 用 Blender（4.2 或更新）打开文件。
2. 鼠标放在中间大窗口里。按 `Z` → 选 **材质预览**，粉色才看得见。
3. 转视角：按住**中键**拖动＝转；**滚轮**＝缩放；`Shift`＋中键＝平移。
   触控板：两指拖＝转，捏合＝缩放，`Shift`＋两指＝平移。

## 刷色

1. 左键点一下头发（整顶头发会亮起橙色描边）。
2. 按 `Tab` 进入**编辑模式**，再按键盘上方的数字 `3`（**面**模式）。
3. 先按 `Alt+A`（Mac：`Option+A`）全部取消选择。
4. 按 `C` ——鼠标变成一个圆圈刷子：
   - 按住**左键**在要改的地方**涂**，涂到的小块会被选中（变橙色）
   - 滚轮调刷子大小
   - 按住**中键**涂＝取消选中
   - 涂完按 `Esc` 或右键退出刷子
5. 右边属性栏找到红色小球图标（**材质**）。列表里有「头发」和「皮肤（会被删）」两行：
   - 点 **皮肤（会被删）** → 点下面的 **指定**（Assign）→ 选中的变粉色
   - 点 **头发** → **指定** → 变回头发色
6. 重复 3–5，直到满意。刷错了 `Ctrl+Z`（Mac `Cmd+Z`）。
7. 按 `Tab` 回到物体模式，`Ctrl+S`（Mac `Cmd+S`）保存，把文件发给我。

小窍门：耳朵附近不好看清的，按小键盘 `/` 可以只显示头发（再按一次恢复）。
