## 十二个模型预设

| 键 | 显示名 | 主要轮廓 |
|---|---|---|
| korean | 韩式碎盖 | 蓬松短顶、碎刘海、两侧贴短、无长尾 |
| wolf | 层次狼尾 | 分开的长刘海、颊侧外翻层、蓬松后脑与碎尾 |
| mullet | 短侧鲻鱼头 | 更短前顶与两侧、较窄且明确的长后颈 |
| curtains | 蓬松中分 | 中间露额、两侧向外弯、短后脑 |
| comma | 逗号刘海 | 非对称侧分、单侧向内回卷 |
| pixie | 精灵短发 | 低体积短顶、短鬓角、斜碎刘海 |
| bob | 法式短波波 | 下颌附近内收的短后发、分开刘海 |
| hush | 轻盈羽毛剪 | 长后发、两侧较短的分层修饰 |
| airbang | 空气刘海长直发 | 窄而稀的刘海、垂直长后发 |
| wavy | 慵懒长卷发 | 长度方向的起伏、侧面宽松波浪轮廓 |
| bun | 松弛盘发 | 发团位于后上方、脸边细碎发 |
| ponytail | 高马尾 | 后脑扎点、离开头骨后垂下的独立尾束 |

这些是适配小比例童话布偶的原创几何简化，并非对真人照片逐根复制。
