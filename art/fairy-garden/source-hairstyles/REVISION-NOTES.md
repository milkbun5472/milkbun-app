# M02 中分微卷：本轮返工记录

2026-09-24。本轮集中处理 M02，并提供独立试换与正侧背截图；不是十二款已经定稿，也不代表用户已认可造型。

| 部位 | 本轮处理 | 仍需对照的差距 |
|---|---|---|
| 前刘海 | 按特写重画两束 C 形轮廓，曲面包住圆头；宽度、内收发尾及厚度分别控制 | 曲面仍比参考平滑，宽面转折与自然发流还可进一步修饰 |
| 中分与头顶 | 前刘海低位起根，独立内层短发；两侧头顶高度错开 | 头顶分层仍有拼装感，不能称为原图复刻 |
| 侧后体积 | 复用原 GLB 后脑真实发束；侧边增加绕头过渡束，接缝边缘埋入内层 | 与新刘海的风格衔接仍需要用户审视 |
| 表面阴影 | 重新计算经过裁切、整形后的法线，移除旧法线造成的斑块；保留原后脑颜色明暗 | 原件烘焙颜色与新发束顶点阴影并非完全相同 |
| 额头 | 新增曲面补旧刘海遮挡区域，皮肤色取自源贴图；原眼、颊、下巴保留 | 眼边、太阳穴仍能看到原网格与补面衔接痕迹 |

截图由 `capture-gallery.cjs` 从最终导出 GLB 生成，未使用参考图替代模型画面。`m02-front.png`、`m02-side.png`、`m02-back.png` 与 `m02-views.html` 对应这版；全部款式的当前截图在 `gallery.html`。

数值验证与美感验收分开：源表面与贴图保全、换发、六项体型端点、复位、手机窄屏由随件脚本和 JSON 记录。庭院现役模型、衣服、动作和应用版本未改。本批为可检查的返工进展，其他款式仍待继续修。
