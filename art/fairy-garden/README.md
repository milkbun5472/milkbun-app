# 微光庭院 · 小人的头发和体型

游戏里那个小人的**身体、脸、材质槽都来自 `apps/fairy-garden/traveler.glb`**（Codex 建的），
这里只做两件事：**换头发**、**调体型维度**。身体和脸一个字都不改。

## 为什么放在仓库根的 `art/`，不放在 `apps/fairy-garden/` 里

`scripts/build-fairy-garden.mjs` 会把 `apps/fairy-garden/` **整个目录**哈希成一个内容指纹。
这几个 `.py` 放进去，等于每改一行注释就让**整个游戏的缓存失效**一次。所以它们住在外面。

## 跑起来

Blender 以 Python 模块的形式装：

    pip install bpy          # 约 374MB，需要 Python 3.11
    python3 art/fairy-garden/preview.py        # 渲三张预览到 /tmp/fairy-doll

图**不进仓库**（一张一兆）。要换输出目录就设 `DOLL_OUT`。

## 量出来的几个数（别凭感觉改）

| 数 | 值 | 从哪儿来 |
|---|---|---|
| 脸的包围盒 | 宽 .478 × 深 .380 × **高 .520** | `traveler.glb` 的 `Face` |
| 头骨中心 / 半径 | `SK`=(0,-.067,1.210) / `SKR`=(.239,.190,.260) | 同上 |
| 眼睛上沿 | z = 1.264 | `Dark embroidered eye` |
| `BROW` | **1.352** | 刘海最低点必须高过眼睛上沿，是照着脸部特写量的 |

⚠️**脸是竖着的蛋形（高 > 宽）**。第一版我自己捏了个正球，同样大的眼睛在正球脸上就成了
「大脸小眼」——她 2026-09-16 一眼看出来。这是这套东西最贵的一条经验。

## 头发怎么做

⚠️**不要拿一个半球扣在头上**，那就是锅盖。Codex 那版好看的真正原因是
**一颗颗有厚度的圆块堆出来**，块之间错位，轮廓才有咬合感。

三个摆放函数，各管一处：

- `cap_shell()` — 贴着头骨的一层壳，头发的底。**比头骨只大一点点**，大了就是头盔。
- `bang()` — 刘海。**按平面坐标摆（y 固定在脸前），不按球面**。
  按球面摆的话它永远贴在天灵盖上，看着就是发际线老高。
- `strand()` — 顺着头骨球面摆的一缕，用来做顶上的碎发和两鬓。

现有五款：`korean`（韩式碎盖）、`wolf`（狼尾）、`mullet`（鲻鱼头）、
`airbang`（空气刘海长发）、`bun`（丸子头）。加一款 ≈ 二十行。

## 体型维度

这个头身比下，「男体/女体」不靠肌肉骨骼，靠四个数，**全都作用在现成的零件上**——
所以以后加一件新衣服只做一次，四个数照样能调它。

| 维度 | 动什么 | 观感 |
|---|---|---|
| `flare` | `Tunic skirt` 的横向缩放 | **最强的一个**：摆开＝裙感，收窄＝直筒衫 |
| `shoulder` | 两只袖子往外挪 + `Tunic upper body` 横向拉宽 | 撑起上半身 |
| `height` | 袜子拉长、靴子下移 | 拔高重心 |
| `head` | 头和五官整体缩放（头发跟着走） | 头小显大人，头大显幼 |

参考值：男 `flare=.78, shoulder=1.20, height=1.14`；瘦高再加 `head=.94`。

## 接进游戏时的两个坑

1. **three.js 里 `clone(true)` 共享材质。** 不给每个实例 clone 一份材质的话，
   给一个人换了衣服颜色，全场都会跟着变。`traveler.mjs` 现在是靠**整个换掉 material**
   才没串色的。
2. **材质槽已经是现成的**，按名字改颜色即可：
   `Character warm peach`(皮肤) / `chestnut hair`(头发) / `eyes`(眼) / `cheek rose`(腮红) /
   `dusty rose wool`(上衣) / `cream linen`(内衬与袜) / `cocoa boots`(靴) / `ochre satchel`(包)。
