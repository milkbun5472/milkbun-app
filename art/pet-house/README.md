# 宠物小屋 · 场景第一稿

3D宠物小屋，可独立预览，也由绒绒小镇正式入口复用同一模型、染色与动作引擎。猫有20根控制骨骼：点「走走」沿地毯缓慢散步，「停一停」减速并落稳抬起的脚。四拍步态、腿部IK、世界坐标落脚和爪子方向锁定配合身体/头/尾的小幅运动；当前路线是预览用的固定安全环线，没有通用寻路。点家具显示场景说明，拖动转视角、双指或滚轮缩放，可切白天和傍晚。

手机默认镜头比原全景放大30%，横屏/桌面放大12%，同时放大场景与猫的视觉占比，不改变猫相对于家具的体型。底部「− / 看猫 / +」控制缩放：「看猫」切到5倍近景并跟随家里散步的猫，再点「看场景」回到默认场景；「全景」恢复1倍、初始视角和位置。缩放范围0.72～8倍，双指按两指中心放大/缩小并平移，抬起一指后能继续旋转，不误触家具。

`pet-camera.mjs` / `pet-camera.css` 是家里与六个外出场景共用的镜头/手势/控件；相机按实际场景容器尺寸计算，可供后续游戏界面复用。正式入口与独立预览共用。

「毛色」可选原色、橘白、奶茶、黑白和浅紫，或分别调整底毛/花纹。UV蒙版保留毛发明暗纹理，保护眼睛、鼻子和内耳；原色直接还原原贴图。仅将毛色写入本浏览器的独立 `lisa-pet-house-cat-look-v1` 设置，刷新可恢复，不修改宠物/角色存档。后台暂停渲染；可见时摆尾持续渲染，关闭摆尾且停止落稳后按需渲染。

- `preview.html`：浏览器入口，复用庭院的 Three.js、GLTFLoader 和 Draco 解码器。
- `room.glb`：奶油墙面、木地板、窗台与窗帘、绿沙发、阅读灯、编织窝、猫爬架、椭圆地毯、玩具篮、水粮碗。每个区域保留 `zone` 标记，玩具与两只碗保留独立 `item` 节点。
- `cat.glb`：Lisa 提供的 `e7667bb2460bb44cd3f56ba8645e00f5.glb` 的手机用派生副本。约2.6万三角面，贴图最大1K，WebP与Draco压缩，含20根控制骨骼/一套蒙皮；行走由运行时计算，没有烘焙动画片段。原始下载文件未改动，原件 SHA256 见 `asset-report.json`。
- `cat_asset.py` / `cat-rig.json`：按原猫实际关节位置绑定并输出运行时关节/步幅/毛色元数据。UV接缝同位置权重相同，导出四权重归一化。
- `cat-mask.png` / `cat-dye.mjs`：1K毛色蒙版（R花纹/G底毛）和材质染色控制。
- `cat-motion.mjs`：四拍慢步、两段腿IK、落脚锁定及头身尾动作。
- `build.py`：可复建的 Blender 美术源。编辑源保留细节物件；仅在导出时按区域和材质合并静态部件，减少网页绘制次数。
- `layout.json`：预览相机、猫的摆位和区域说明的共同来源。Blender 坐标为 Z 向上，浏览器坐标映射为 `(x,z,-y)`。

重建（替换路径为本机原件与证据目录）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background \
  --python art/pet-house/build.py -- \
  --cat /path/to/e7667bb2460bb44cd3f56ba8645e00f5.glb \
  --evidence /path/to/pet-house-evidence
```

输出网页资产至本目录，预览图及可编辑 `pet-house.blend` 至证据目录。只需重新导出时加 `--skip-render`。每次源或素材改变后更新相应预览脚本/资产指纹；猫与步态为 `pet-motion-5`，狗与共用选择/尾巴控件为 `pet-dog-2`，小屋预览为 `pet-dog-2`，街区预览为 `pet-career-6`，共用镜头脚本为 `pet-camera-2`，房间仍用原 `pet-house-1`，正式资源图由 `scripts/build-fairy-garden.mjs` 统一生成 `fg-*` 内容指纹；修改共用引擎后必须重建并随 App 发版。

浏览器验证（先在仓库根启动本机 HTTP 服务）：

```sh
PET_HOUSE_URL=http://127.0.0.1:18952 \
PET_HOUSE_EVIDENCE=/path/to/browser-evidence \
node art/pet-house/check-preview.cjs
```

另运行 `node --test art/pet-house/cat-motion.test.mjs` 检查落脚连续性、IK长度/极端目标、蒙皮资产、地面高度与保存值校验。浏览器验证模型加载、区域点击、光照切换、拖动/缩放/复位、刷新、320/390/430宽度的控制布局，以及一分钟散步中真实蒙皮脚底的滑动/高度和骨骼落点，停止落脚、预设/自选毛色及刷新保存。实体iPhone性能未测。街区寻路与实体门已经接入，手机第三小世界入口见 `apps/pets`；正式小镇已接入喂饭、零食、陪玩、休息、摸摸与自主观察；角色参与和共同养育事件待做。

`node art/pet-house/check-camera.cjs` 用真实Chrome验证家里及名册中的六处外出场景在320/390/430及932×430横屏的默认视觉放大、控件触区、按钮/双指缩放、上下限、看猫近景/散步跟随、双指转单指无误点及复位。设置 `PET_CAMERA_URL` 和 `PET_CAMERA_EVIDENCE` 可复核线上/保存截图与结果。

## 猫狗与尾巴

「陪伴」可切换猫咪/狗狗，小屋和街区共用 `pet-companion.mjs` 的资产、归一化、染色、步态绑定与设置。狗是 Lisa 提供的 `44b922b034560250f105585ed17529e0.glb` 的派生副本，约2.6万三角面、20根骨骼；原件的尺寸与 SHA256 见 `dog-report.json`。猫狗各自记住毛色与尾巴姿态，选中的宠物在家里、街区和六栋屋之间沿用。

步态用一个主周期按左后→左前→右后→右前的顺序落脚，支撑期占周期68%，迈步中交替保持两足/三足支撑，肘关节/后膝保持解剖方向，落地脚锁在世界坐标。腿部蒙皮隔开肚子与前后腿，抬脚幅度较小，身体随支撑侧轻移。街区步速按各自腿长和步周期计算，避免极高步频。起步从当前落地位置开始，其他脚在下一个抬脚边界加入；停步走完剩余摆动。正式室外按速度选择对角小跑（约每秒2.6～2.8周期），保留1.1×体型的移动速度，转弯先换脚转身再前进。引擎按真实位移/角速度持续预测落点，并按支撑脚收低重心、跨路面高度后逐渐恢复。完整头颅（前脸、后脑与耳朵）统一绑定头骨，仅颈部过渡，头骨继承胸部位置/旋转后再叠加小幅稳定动作。

「尾巴」能开关摆动、调抬低（±25°）/左右（±35°），可恢复自然姿态。三段尾骨累积旋转并连接到骨盆，根部带动尾端。猫轻摆、狗摆幅和频率较大；这些是预览动画设置，并非情绪/养育存档。

只重建宠物（不重新导出房间）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background \
  --python art/pet-house/build-pet.py -- \
  --species dog --source /path/to/44b922b034560250f105585ed17529e0.glb \
  --evidence /path/to/pet-evidence
```

猫改用 `--species cat` 与猫的原始路径。`cat_asset.py` 提供唯一的绑定/蒙版规则，`build.py` 和 `build-pet.py` 共用。

`node art/pet-house/check-companion.cjs` 检查真实猫狗各一分钟步态、四肢主周期同步、两足/三足重叠支撑、IK落点、实际蒙皮摆尾、尾巴设置分宠保存/刷新、320/390/430/横屏控件与六栋屋中的狗；同时导出一整周期侧面逐帧图以便人工看步态。

`node art/pet-house/check-pose.cjs` 直接检查猫狗导出蒙皮的前脸/后脑/耳朵顶点：步行及停步时头颅内部距离保持不变，抬脚/落脚边界无跳位、IK目标可达；也检查猫狗以正式速度走完街区六条路径，转向不瞬跳、足部目标无IK夹断；输出完整侧面周期图。使用 `PET_HOUSE_URL` 与 `PET_HOUSE_EVIDENCE` 指定地址/证据目录。

心情体态由 `pet-mood.mjs` 提供同一词汇：开心、放松、好奇、困困、警惕、闷闷。正式游戏按真实照料/精力/心情变化；独立预览点「体态」试六种状态。猫会调整耳朵、尾巴和伏身，狗会摇尾、歪头与轻微邀玩；体态平滑过渡，行走时减小身体幅度以保持踩地。耳朵继承完整头部变换后才局部旋转，进食和睡觉也共用它，避免脸与后脑拆开。`check-mood.cjs` 检查真实蒙皮、头部刚性、落脚、快步和手机面板。

狗狗的躯干比猫高，头颅蒙皮按狗自身高度划出后脑和颈部过渡；上背部毛簇留给胸/骨盆控制，低头和犯困时不会被头骨牵起。`check-back.cjs` 检查真实Draco解码后的401个上背部顶点，在抬低头时保持原位，并输出各体态背部近景；`check-pose.cjs` 继续核验脸与后脑整体运动。狗模型、骨骼元数据和独立资产指纹为 `pet-dog-4`，正式入口仍由资源图统一换指纹。

## 骨骼照料动作（2026-10-04）

`pet-action.mjs` 统一家中照料、窗边/街头闲逛与街坊动作的姿态取样；`cat-motion.mjs` 用同一套四肢 IK 实现收腿坐下、胸腹下沉趴睡、撑起后再走、吃喝前倾、摸摸与闻东西、叼起/叼放玩具。睡觉不再侧倒整个模型；头、耳与脚爪保留形状，胸腹轻微呼吸，尾巴安静收在身侧。原走路四拍与小跑对角节奏、招呼回应、照料拒绝和完成结算沿用。外貌预览只重置动作姿态，不推进照料。

`pet-skin.mjs` 在独立克隆的蒙皮上修正猫背误跟头、尾尖残留躯干权重与腿根硬切换，原压缩 GLB/纹理不改；`pet-eyes.mjs` 在真实脸部材质上闭眼、轻眨，不加载新图片。重绑保留正在进行的姿态、心情和招呼阶段。

`node --test art/pet-house/pet-action.test.mjs` 检查真实关节长度、权重边界和爪底绑定。`node art/pet-house/check-actions.cjs` 解码两只真实模型，逐一检查21种动作、7种心情的皮肤落地、头骨刚性、腿部可达与过渡，并输出所有截图及睡眠侧面、重绑证据；沿用 PET_HOUSE_URL/PET_HOUSE_EVIDENCE。截图不是额外的动画系统。实体 iPhone 尚未测。

猫狗闭眼共用清楚的弧线；宠物自己的眼位遮罩同步替换虹膜颜色、眼球法线、粗糙度与金属度，闭眼不留下灰色球面或反光，原几何与阴影不变。程序缓存键区分猫狗，防止混养后复用错误眼位。`check-face.cjs` 用两种加载顺序和正面/两侧的站立、回应街坊、趴睡姿态检查真实 WebGL 睁闭眼：虹膜消失、闭眼线仍可见、鼻嘴舌头像素不变。沿用 PET_FACE_URL/PET_FACE_EVIDENCE。

`catLooseFragmentIndices` 焊合 UV 接缝后只移除猫咪后腿前面两个微小区域内的独立网格岛；连接到腿身的三角面保留。真实资产删除505个三角面（两碎块及八个微小碎片），不改源压缩 GLB。`pet-details.test.mjs` 回归连接爪身保护、双侧碎块、幂等和猫狗着色缓存隔离。
