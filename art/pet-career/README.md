# 宠物小世界 · 职业与日常场景

与宠物小屋共用奶油、浅木、鼠尾草绿和蜜桃粉材质，以及现有猫模型的比例。共有六个真实3D场景，独立美术预览，不包含打工、收入、存档、角色AI或可玩解谜。

- 面包店：圆面包柜台、看板猫踏台、收银机、烤炉、面粉袋、纸袋、零钱罐、面包架和客人小桌。
- 花店：花桶、植物架、包花桌、丝带、门口玻璃门、落花瓣、猫猫踏台和邻居等候凳。
- 侦探小巷：两间店屋、雨棚、路灯、公告板、信箱、掉落信封、小脚印和旧物摊。
- 便利店：饮品零食货架、冷柜、收银机、小票、贴纸、收货纸箱和空纸箱；猫踏台与狗狗门口等候垫、水碗。
- 公园：草坪、弯石径、圆树冠、靠背长凳、野餐布/篮、低跳栏、小球、玩具绳与公共饮水碗。
- 咖啡店：咖啡机、吧台猫软座、杯架、小黑板、窗边软座/抱枕、小圆桌/杯子/菜单、狗狗迎宾垫与饮水碗。

`preview.html?scene=bakery` 为默认入口。顶部切换六个场景或返回现有家里预览；点家具查看区域说明，拖动旋转、双指或滚轮缩放，切白天/傍晚和全景复位。切换场景会重载页面释放旧场景。猫复用 `../pet-house/cat.glb`，本批不复制或修改猫、家里场景、App主屏或用户数据；此处猫只作静态比例示意，家里窗口的动作/毛色工作独立维护。猫狗场景共用，保留高处猫踏台和地面狗狗垫；本批没有新建狗模型或接入猫狗职业。

镜头与家里共用 `../pet-house/pet-camera.mjs` / `pet-camera.css`：手机默认近30%，横屏/桌面近12%；底部「− / 看猫 / +」缩放0.72～8倍，「看猫」拉到5倍近景，「看场景」回默认，「全景」恢复1倍。双指按手指中心缩放并平移，转为单指可继续旋转，不误点家具。只改变镜头，不放大猫相对家具的体型。此处猫仍为静态展示，职业玩法未接。

`scenes.json` 是预览导航、加载、建模选项和回归测试共用的场景名册；每处独立缓存版本保留旧三处资源缓存。每个场景有同名 `.json`（相机、猫位置、区域说明）和 `.glb`（合并后的手机预览资产）。`build.py` 保留独立源物件，只在导出时按区域与材质合并；GLB保留 `zone` 标记，供后续接场景交互。可编辑 `.blend` 与出图存证据目录，不放进网页下载。Blender效果图中的猫会将导入骨骼的静止姿势烘成静态网格，排除Blender骨骼显示用的小球后再计算比例；网页继续直接复用家里的GLB。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background \
  --python art/pet-career/build.py -- \
  --scene bakery --evidence /path/to/evidence
# scene 可换 florist / alley / store / park / cafe；只导出可加 --skip-render
```

仓库根启动HTTP服务后：

```sh
PET_CAREER_URL=http://127.0.0.1:18954 \
PET_CAREER_EVIDENCE=/path/to/browser \
node art/pet-career/check-preview.cjs
```

浏览器回归覆盖六场景加载、模型比例/区域、实际家具点选、灯光、旋转/缩放/复位/刷新、导航及320/390/430窄屏。共享镜头回归另运行 `node art/pet-house/check-camera.cjs`（`PET_CAMERA_URL` / `PET_CAMERA_EVIDENCE`），覆盖七场景窄屏/横屏、默认放大、看猫、真实双指事件、缩放边界和复位。实体iPhone性能尚未验证。预览脚本/样式采用 `pet-career-3`，场景GLB/JSON按名册的各自版本加载，共享镜头为 `pet-camera-1`，猫为 `pet-house-2`，不修改App版本。

## 后续玩法约定（尚未实现）

职业是改变宠物的长期生活经历：性格影响适合/讨厌的工作，出门产生故事、物品与关系，经历继续改变习惯。允许拒绝上班、装睡、用零食商量，以及快乐的无业日子。收入进宠物自己的小金库，记录真实打工收入和购买；宠物偶尔自主花钱。角色可以找兼职、参与花钱，或与用户持不同职业意见。履历记录各职业和无业天数。

职业内容应围绕场景、事件、带回物品和变化扩充；不用固定派遣时长加金币代替职业生涯。拒工/诱惑、职业事件、邻居宠物、角色共同养育、小金库与自主购买、猫咪侦探解谜均须另接真实状态后才能称完成。当前信封、脚印和公告板只是美术道具，没有虚构“今天已经发生”的事件。
