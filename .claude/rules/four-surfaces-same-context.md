# 四处一样喂（Lisa 2026-08-24 立）

**单人线上 / 单人线下 / 群聊线上 / 群聊线下，喂给模型的东西默认必须一样。**
除非某一处被【明确点名】需要特殊处理，否则任何一处有的层，另外三处都要有。

## 为什么立这条

她 2026-08-24 报：群里裴照川开始说霸总话，而同一个群里的双胞胎完全正常。
查下来不是霸总禁令的问题，是**群聊把人设砍到了 200 字**（单聊是全文），而且
群聊压根不走 `buildBundle`——印象卡、心情、好感度、长期记忆一层都没有。
他在群里只剩「一个古代王爷」这个标签，剩下的空白由训练先验补上，那就是网文霸总。

**截断对谁伤害大，取决于截断之后剩下的标签有多刻板。** 双胞胎是「现代年轻人」，
fallback 无害；王爷不是。

这已经不是第一次了，同一个形状反复出现：

| 什么时候 | 哪一处漏了 |
|---|---|
| v54.80 | 同人文没吃到线下那套叙事准则 |
| v55.52 | 线下没吃到小剧场那五条（镜头/成段/一拍） |
| v55.66 | 线下完全没有回声式反问的防线（禁令和刀都只在线上） |
| v55.86 | 群聊线上完全没有回声防线 |
| v55.87 | 群聊人设截断到 200 字、没有印象卡/心情/好感度 |
| v55.89 | 群聊三处私聊围栏都只挡「别人的私事」，没挡「自己的私事被端上台面」 |
| v55.90 | 群聊没有用户人设／情侣状态／年龄／此刻在做什么；霸总语气禁令只埋在单聊的行程块里当从句 |
| v55.91 | 群聊把模型放在【导演位】上（单聊是「完全代入『某某』」，群聊是「你在导演一个群聊」）；「彼此不熟就照不熟来」只写在两人旁观局那一支里 |
| v55.95 | 实时心情的更新指令写好了、声明了一次，然后【从没被引用过】——四处一个字都没收到 |
| v56.09 | 「每几轮自动抽取记忆」单聊线上／单聊线下／群线下都有，只有群线上没接——它只挂着 150 条才动一次的滚动总结 |

每次都是「这一层当初只写在一处，别处没跟上」。所以默认改成【四处一样】，
差异必须是**显式的、写着理由的**，不能是忘了。

v55.90 还多学到一条：**一层规则如果只作为某个可选块的从句存在，它就跟着那个块一起消失。**
「不许滑进居高临下的训话腔」当初写在【今天的行程】那一段里——角色今天没排日程，
schedNow 为空，整段不 push，这句也就没了；群聊更是从来不发行程这一段。
所以：**能独立成立的规则就让它独立成立**，别挂在别人身上搭便车。

v55.91 学到的是这条规律的另一半：**四处一样喂，喂的不只是【料】，还有【站的位置】。**
前面几版一直在补群聊缺的上下文层（人设全文、心情、好感、印象卡、情侣状态、年龄），
料补齐了，王爷在群里还是霸总——因为单聊的任务句是「完全代入『裴照川』」（你就是他），
群聊的任务句是「你在导演一个群聊」（你在旁边写他）。导演写「一个古代王爷」，
写出来的就是这个类型的通用样子。
（群聊也发 ONLINE_CHAT_RULE_V2 里那句「完全代入当前角色」，但群里有三个人，
「当前角色」没有指代对象，这句话是空转的——**一句话在别处成立，不等于在这处也成立**。）

v55.95 是同一个形状的极端版：**声明了但没人引用，比压根没写更坏**——
看代码以为已经在发了。旁边那条心声（`_normalThoughtTurnHint`）是拼进去的，
所以心声一直在动、心情十三个小时纹丝不动。
新加一层规则时，光看到常量存在不算数，要顺着拼接链一路看到它真的进了 system。

**砍层的唯一合法理由**：这一层**大多数轮次根本用不上**（比如论坛回声——
十轮里九轮用不上，v56.14 改成按需触发）。这是「这一轮用不用得上」的问题。

除此之外，该给的层一律给足。人设尤其要给足：v55.87 那次群里的王爷变霸总，
病因就是**人设只剩 200 字**（只剩「一个古代王爷」这一个标签，空白由训练先验补上），
**放宽到 6000 字是修好它的那一步**。v55.91 那次是**站位**（模型被放在导演位上）。
两次的病因都不是上下文的总量。

## 落地要求

1. 新加任何一层（提示词常量、兜底刀、状态字段、上下文块）时，四处都要接上。
   接不上的那一处，在代码里写清楚为什么。
2. 已知的**合法差异**（有理由，不算漏）：
   - **言秋（`engineerEyes` / `notRoleplay`）**：他不是被扮演的角色，扮演类规则一律不发。
   - **封闭群（`!memoryInterop`）＝只进不出**（她 2026-08-24 定的）：
     **读一律给**——记忆库、长期记忆、印象卡、长出来的自我、人设全文、心情、好感，
     角色在哪儿都得是完整的自己，不能一进闭群就退化成一张标签；
     **写一律封死**——闭群里发生的事不写回记忆库、不动好感、不动心情与状态卡、
     不驱动朋友圈/论坛/悄悄话、不结算钱包、不回流进单聊（群回声）。
     唯一还归互通群的读项是【实时私聊窗口】：闭群那边有自己的 preJoin（入群前私聊）
     当这一档，两者不叠加，否则同一段私聊会进两遍。
     一句话：**闭群是平行沙盒，读主线、不写主线。**
   - **群里的行程**：单聊发整张【今日安排】，群里只发「此刻正在做什么」这一行——
     一人一份完整行程会撑爆上下文，而她按次计费。决定语气和连贯性的是「此刻」那一句。
   - **小剧场 / 同人文**：平行时空，不引用主线记忆与关系。
   - **数字生命**：不发扮演三件套。
3. 群里每位成员的私有层，必须落在**那位成员自己那一段**里，并带隐私围栏
   （见 `interop` 的 memLines 与 preJoin 的写法）——绝不许合成一块共享注入。
4. 人设不许再用固定字数截断。按在场人数分预算（`groupPersonaBudget`），
   每人封顶 6000 字、总预算 30000、地板 1500——她的人设普遍 4500+，
   五人以内的群谁都不该被砍。
5. 加任何一条【写】主线的动作（记忆、好感、心情、状态卡、钱包、动态计数器）时，
   先问一句「封闭群里发生这件事，该不该影响主线」。默认答案是不该。
