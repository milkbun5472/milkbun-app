# 提示词【怎么发】跟【发什么】一样能决定成败（Lisa 2026-09-06 立）

「四处一样喂」那条管的是**发什么层**（人设、心情、记忆、反八股…）。
这一条管的是**怎么发**：同一段字放在 system 里还是 user 里，是两件事。

## 事情长什么样

「Ta 眼里」那两枪（建卡、复看）在 Gemini 上被拦了几个月，界面上只写「没解析出卡」。
她 2026-09-06 一路试下来：**写过卡的角色全失败，新角色能过**；
主聊天天天带着**同一份人设、同一个模型**在跑，一次没被拦过。

差别只有一处：**主聊天把人设放在 system 里，这两枪把人设当成 user 的正文发出去**。

| 放哪儿 | 上游读起来是 |
|---|---|
| user | 「用户正在要求我分析这个人」 |
| system | 「这是给你的角色设定」 |

她那份人设里有「姐姐」「年龄差」「调情」，而那十块里三块问的是
「她的软肋」「什么招对她管用」。**两样凑在 user 那一栏，就是一个人在要求
分析另一个真人的弱点**——输入过滤器拦的是这个。挪进 system 就变回
「你是这个人，写写你怎么看她」，当场通了。

## 规矩

**一次性生成调用（问一次、要一份 JSON/一段正文的那种）：料全放 system，
user 只留一句触发。** 这个 app 里周刊、朋友圈、悄悄话本来就是这么写的：

```js
callAI(p, sys /* 人设＋世界书＋记忆＋料，全在这儿 */,
       [{ role: "user", content: "开始。" }], { maxTokens: … });
```

⚠️**判据一句话：别处是怎么发的？** 别人是「料在 system、user 一句话」，
你这儿把一大段料塞进 user，那不是风格差异，是这一处没跟上。

⚠️这跟「一层写在两处，第二处没跟上」是同一个病。那次一口气揪出五处，
全是「别处都做了、只有这两枪没有」：加固版 JSON 解析、后台线路、
世界书那扇公共门（门上就写着「所有非主聊天功能都必须走它」）、发送形状。
**查一处功能不对劲时，先问「别处怎么做的」，别急着想新办法。**

## 顺带立第二条：报错里必须带着【我没看懂的那个东西本身】

那三轮全浪费在这儿：抛的是 `new Error("没解析出卡")`。
**那是一句只描述「我没看懂」的话，不含任何能往下查的东西——是个死胡同。**
改成带上模型真正回的那 320 个字，病因当场就露出来了。

```js
// ❌ throw new Error("没解析出卡");
// ✅ throw new Error("没解析出卡。他这回答的是：\n" + String(raw || "").slice(0, 320));
```

⚠️给她看的那句照旧翻成人话（她不该读异常原文），但**原文另存一份、点开才看**。
翻不出来就丢掉原文＝她和我都永远查不下去。

⚠️同理：**闸自己坏了的时候，全绿什么都不证明。** 那次拦截名单里四条正则的
`\b` 写成了真的退格字节 `0x08`，从写下来那天起一次都没匹配过——
病因因此多藏了三轮。看不见的字符只能让机器扫（`test/no-control-chars-64-43.test.js`）。
