# 微光庭院

秋秋机中的独立 App。主屏点「微光庭院」，选择角色入住，也可先用示例同行者试玩。源码只维护本目录；父页接入在 `js/fairy-garden.js`，通过同源 iframe 复用完整游戏。

## 已实现

- 下方行动栏可折叠；地图支持双指捏合、滚轮、放大/缩小按钮，点比例恢复默认大小。视图偏好记在本机，双指与拖动不会触发行走。
- 庭院 ↔ 萤光林地，点地面绕障行走。取水、采铃叶草与荧光菇、炼月露、养花、采收再种；没有通关终点。
- 独立游戏日期、晴雨与暮色，前台约 1 秒推进 1 游戏分钟，23 点到次日 7 点。后台、菜单和聊天时暂停时钟；没有离线收益。睡觉和坐一小时会推进游戏。
- 同行者三种本地日程偏好，按日期天气活动、自动跨图、每天一次晨露照料；可以跟随、等待、前往地点或恢复日程。共用寻路避开玩家，优先靠近一侧停留。
- 绑定角色的完整人设与公共文风，聊天使用角色专线，未设置时回退创作线路。给模型当前现场、背包和此角色最近的游戏对话；一轮可执行一个白名单行动，物资与路径由游戏结算。没有自动后台 AI 请求。
- 一个共同世界，换同行者保留资源；每位角色的游戏对话分别保存。游戏不读写主线聊天、记忆、好感、现实日程。
- 父页通过现有 `saveJSON/loadJSON` 保存 `x_fairyGarden`，正常手机备份可带走。模型失败可重试；离开、换存档、换账号后的旧请求不会写入新档。接口密钥只留父页。

## 当前范围

人物仍用共用布偶外形；日程目前选择本地偏好，尚未按人设生成。一次只有一位同行者；没有多人同时入住、自定义形象、室内、语音。花藏仅累计收获，薄雾只有日历描述。玩家主动行走尚未反向避让同行者。

## 独立预览与缓存

本目录仍可通过普通静态服务器独立打开，用旧键 `fairy-garden-prototype-v1`（内部版本 3）；旧 v1/v2 存档可迁移。该独立预览与手机的存档分别保存。不要另复制一套代码维护。

游戏资源变动后执行 `node scripts/build-fairy-garden.mjs`，为 ESM、纹理模型、样式与入口生成统一内容指纹；发布手机仍执行仓库的版本更新流程。`sw.js` 将 iframe 文档与首页分开缓存。Three.js 的许可证在 `vendor/THREE-LICENSE.txt`。

## 验证

- `node --test apps/fairy-garden/*.test.mjs test/fairy-garden.test.js`：路径、跨图、物资守恒、迁移、天气日程、靠近停留、goto/wait、请求形状、行动白名单、离线首页隔离。
- `scripts/checks/fairy-garden-browser.cjs`：隔离浏览器虚拟角色，拦截外部网络，以模拟模型验证主屏进入、嵌入加载、聊天落实行动、失败重试不重复、换角色隔离、换档拒绝旧回复；390×844 与 375×667 截图和输入框位置。设置 `PLAYWRIGHT_MODULE` 与 `GARDEN_TEST_URL` 后运行。
- 真实模型文风与 iPhone 真机性能待 Lisa 体验；测试不使用真人存档、真实 API 或云数据。
