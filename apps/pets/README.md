# 绒绒小镇

小世界中的第三个正式入口，沿用 `x_fairyGarden`／`x_fairyGarden::角色::房间` 的旅程存档与原备份、云同步。庭院、列车、宠物的进度分别位于 `worlds.garden/train/pets`，同一档的身份、同行者、journey、聊天记录保留；原 `world` 仍只镜像庭院。新宠物房间沿用选角色、建房间与记忆权限流程，不额外新建一套宠物存档键。

第一次进入可实时预览并设置名字、五种毛色或自选底毛/花纹、胖瘦80–125%、大小70–130%。胖瘦只改变身体网格的宽度，脚爪与头脸保留，大小等比缩放。眼、鼻和耳内继续受原UV蒙版保护。草稿不自动落盘；确认成功才进入街区，取消恢复已保存的设置。不同档的宠物外观独立，刷新和跨世界回来保持原猫。可以选择猫咪或狗狗，两者共用街区与室内；种类也按存档独立保存。

默认进入公园街区，点地面绕障走路、拖动与双指缩放；六栋房子可走到门口进入家里、面包店、花店、便利店、咖啡店和侦探小巷，出门恢复门外位置和视角，室内点家具和近距离看猫。宿主「去别处」可以改宠物、回同档庭院/列车或选另一档；庭院花册、列车下车页也能进入同档宠物世界。

进度每3秒、走到目的地、进出屋和离开时保存。后台停止行走，保存失败暂停新操作并阻止离开，重试成功再继续。身份校验阻止已切换的存档被旧iframe写入。屋内照料、角色共养和第一份面包店职业按同档保存，见下文。

## 资源与压缩

正式游戏直接复用 `art/pet-career/preview.mjs` 渲染器、现有猫运动/UV染色、庭院寻路和手势、共用室内镜头，不复制模型或渲染器。现有派生GLB已经使用Draco压缩并按区域/材质合并；猫为276728字节、狗为331360字节、最大1K的WebP贴图，街区625444字节。正式入口染色蒙版再由899691字节PNG压成366706字节无损WebP，解码RGBA逐字节相同；眼鼻保护不变。可重跑 `scripts/compress-pet-assets.py`，报告在 `compression.json`。每间屋独立加载，退出释放其网格/材质/贴图，街区保留用于返回；建模脚本、Blender源与测试不进入游戏下载。应用像素比限制1.5，静止时按需渲染。

`scripts/build-fairy-garden.mjs` 已把 pets 和共用宠物资产加入现有庭院/列车资源图，统一按内容产生缓存指纹；SW分别缓存各iframe文档及同源资源。仅缓存已访问的资源，未访问房间不保证离线可用。

## 验证

`node --test apps/pets/state.test.mjs test/pet-world.test.js` 检查非法档恢复、外貌边界/身体变形、独立快照、真实压缩资产与三世界入口。`scripts/checks/pet-world-browser.cjs` 使用隔离Chrome与真实宿主，检查320/390/430预览/触区、按档取名毛色胖瘦大小、草稿不保存、保存失败留页、实际走门进屋、庭院/列车往返、不同档隔离及新房间锁定角色。实体iPhone未测。

## 屋内照料（第一批）

家里六个按钮对应添粮、零食、玩球、小老鼠、休息和摸摸；点饭碗/玩具篮/窝/沙发或宠物也可以互动。实际行走复用庭院导航器，按现有家具脚印避障，身体大小决定边距；吃饭在碗边消耗碗内粮并恢复饱腹、零食单独喂一小口、吃饱会拒绝，玩耍在地毯追移动玩具消耗精力/提高心情、休息在窝或沙发边躺下并恢复精力，摸摸慢慢提高亲人倾向。睡觉时要叫醒才能换活动，太累不想玩、连续摸会挪开，碗内有粮不重复加。无金币成本、健康惩罚或付费AI。

闲着12秒后会按饱腹/精力和活动倾向自行吃饭、休息、追玩具或看窗外；自主看窗外可被玩家互动打断。`care.mjs`共管有边界的数值、任务/阶段/时间、种子随机、性格/玩具/休息偏好、最近8件小事，存在原worlds.pets.care；旧档默认补齐，恢复进行中的活动。状态只按可见前台时间推进，背景/设置/去处/「看看它」暂停，不根据墙钟补算离线。保存失败暂停操作，重试成功再继续；仍按档与角色房间隔离。

「看看它」复用宿主Head与整页单一滚动正文、原0.4底部安全区：饱腹/精力数值和进度条、心情/当前行为文字、脾气/偏好文字、游戏经过时间的小事。不在iframe另造标题栏。菜单可进入，游戏顶部也有入口；外面可从状态页回家照料。`care.test.mjs`检查旧档/坏档、移动不给奖励、可见时间/暂停、偏好与拒绝、自主选择、0.7–1.3大小所有家具路径；`pet-care-browser.cjs`作为原第三世界浏览器回归的一部分检查真实行为/布局/暂停/活动刷新。

## 面包店职业与小金库

`worlds.pets.career` 保存愿意/拒绝、一次零食再邀请、三段试工及当前事件、工作印象、收入、物品、账本与履历。每天最多一班；五分钟前台照料时间算一天，后台、菜单、离线暂停。工作只在实际进入的面包店推进，事件需玩家或TA从当前选项拿主意；三件完成后手动收工才能结算一次。疲劳暂停，可回家恢复或中止不结工资；旧照料档从当前游戏日开始，不伪造既往工作或休息历史。猫狗共用职业规则，意愿受各自精力/心情/亲人倾向/工作印象影响。

工资只进宠物自己的 balance，账本记录每班收入及买零食/自己的球。带回的小面包和零食在 inventory，太饱或忙着时不能喂。小球所有权直接决定玩具角是否摆出自己的球，点击复用原玩球流程。`home-souvenirs.mjs` 从同一库存/履历投影出饭盆旁的面包篮、小球、首工纪念；Three程序几何和一张现场生成的纪念印刷纹理，不增加GLB或下载图片。分零食/小面包只在家中开始原进食流程，接受后扣一次库存，task.food随档保存，走路不加饱腹，实际吃时逐渐恢复；离家取消已分出的这一份，不再重新扣。firstTrial在首次实际收工时保留日期、当时名字、收入与三项实际决定和决定者，独立于短近期日志；旧档不补造。纪念可从墙进入原履历整页，TA沿原聊天事实读同一投影，无AI自动调用。其他职业、自主购物、TA自行找兼职暂未实现。

动作窗口的接口：`PetGame.career()` 为独立只读快照，job.phase 为 working/choice/ready/tired，event.id 精确标识当前决定。`PetGame.careerAction(action, options)` 执行邀请/再邀请/选项/收工/购物等，由共用纯状态引擎校验并落盘；保存失败回滚职业和照料变化，冻结到重试成功。成功或拒绝后发出 iframe 内 `pet-career-change` DOM 事件，detail 含 action/accepted/text；动画消费事实，不重复结算。职业引擎不修改骨骼或姿态。

TA建议共用原 ask、房间上下文与记忆权限，手动发送一次才请求模型。work-choice 只接受本次世界事实里的事件及选项；应用时再次校验当前事件，迟到/无效主意不会写进另一件事。实际选项注明拿主意的人，聊天返回职业页再回场景继续。

`career.test.mjs` 检查拒工随机持久化、邀请门禁、三阶段、前台/地点暂停、刷新事件、重复结算、库存购物、取消与休息记录。`PET_CAREER_CHECK=1` 开启完整宿主浏览器职业回归，涵盖猫狗、320/390/430、TA决定、刷新、失败保存回滚与三世界往返；不使用真实私档或付费模型。

## 宠物页面的材质与书页

宿主 `panels.css` 只作用于 `.pet-session`：照料名牌/记录、面包店试工单、零钱袋/小票、履历册、街区路牌与旅程明信片，毛色与种类决定旁边的小头像。职业生活册用贴页索引分今天/钱/履历，支持键盘方向键；每张书页及去处页独立记阅读位置，从TA商量或子页回来恢复。一份PetPanel负责整页正文和0.4安全区底栏；沿用Head，iframe保持挂载并暂停，打开整页时隐藏画面以露出外壳纸纹。外貌控件仍在实时模型下方，按原预览协议保留模型。没有改数值、职业结算或模型动作。

`PET_PANEL_CHECK=1` 的浏览器回归检查猫狗320/390/430，状态/三张书页/去处、头栏、单滚动、底栏尺寸和逐层返回位置；职业回归同时覆盖新聊天页和实时选择。
