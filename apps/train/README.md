# 远行列车

小世界里的正式列车入口，与庭院共用 `x_fairyGarden` 旅程记录及原存档钥匙。`worlds.garden` 与 `worlds.train` 分开保存世界进度，`journey`、同行者与原聊天记录留在同一条记录；庭院同时镜像到旧 `world` 字段。已接入摄影、拼图、角色坐卧和聊天气泡。

- 小世界选择列车后，现有庭院档全部可用。直接进入开启一趟随机时间、随机季节日期、随机初始风景的旅程；新档继续走既有选角色、设置房间权限流程。
- 庭院点击林边车站的“登上列车”，先走到站台、保存成功，再继承当前 day/minute/epoch；因此初始时间、季节与天气和庭院完全一致，初始风景随机。
- 列车按森林→田野→海岸循环。每段160距离单位，最后40单位逐层引入下一段，远景先变、近景后变；路程位置连续保存。湖畔与海镇仍有观景慢行。
- 每现实秒推进2游戏分钟，午夜换日，沿用庭院14天一季、四季顺序和确定性的季节天气抽样。天气不因刷新重抽；观景慢行不影响时钟速度。切到后台暂停，不补算离开时间。
- 房间中重新打开正在进行的列车存档会续接；从小世界明确点“列车”会开始新一趟随机旅程。每3秒保存，隐藏/退出/下车前再次保存；失败暂停推进并阻止离开。
- 下车选择庭院，恢复该档的庭院日期、材料与进度，在车站落地。上车环境只作为列车出发快照，不把列车旅行天数扣到花圃和庭院任务上。
- 正式界面有三种观景视角、宿主下车页与旅程设置页，没有天气/季节/时间/倍速/跳段/外壳调试控件。旅程设置可回到共用庭院存档列表，或复用同行者选择页与原房间创建表单，先设定名称/设定/记忆权限再开新档，原档不换人。使用公共 Head；页面独占一个iframe，切换销毁上一世界渲染。

列车与艺术预览共用 `art/train-carriage/view.mjs` 和景片模块，不复制渲染器。`scripts/build-fairy-garden.mjs` 统一指纹庭院、列车及共享景片依赖；修改后运行该脚本和应用版本脚本。

验证：`travel.test.mjs` 使用庭院真实状态构造函数验证继承、随机入口、跨日换季、段落接续；`scripts/checks/train-world-browser.cjs` 使用干净浏览器、真实宿主与场景验证同档往返、存储失败、站台上车和手机布局，完全不访问用户浏览器存档。

`train-settings-browser.cjs` 检查列车内回选档、选择另一位同行者、真实房间设置表单与创建写入，并确认原档身份和材料保留。

## 窗景拼图

列车底栏「拍照」保存当前窗景的 900×600 JPEG；「拼图」在桌上打开照片选择、12/24/48/80 片和三种参与方式。`puzzle.mjs` 统一生成共享切缝、随机散片、落位判断和同行者动作目标；切缝种子、照片、每片位置/完成者保存在 `worlds.train`，再次登车也保留。桌面支持指针拖动、双指缩放/空白平移与复位。重新切图需要第二次确认，保留照片。

「一起拼 / 看 TA 拼」由可见光标逐帧拖动；熟练度按同行者 ID 稳定生成，影响思考间隔、拖动速度、试错率与先拼边框的倾向，不推断真人能力。文字用宿主既有 `ask` / `sharedStyle` / `roleContext`，显式列车上下文替换庭院动作；房间权限和历史沿用原 `record/recordFor`。只在选择参与、阶段进展（至少45秒间隔）、完成或主动说话时请求；没配线路仍可手动/观看拼图，文字显示配置提示。照片数据不发模型，模型得到照片地点/时间标签和实际拼图状态。尚无角色实体手部动画或视觉模型识图。

验证：`node --test apps/train/*.test.mjs`；`scripts/checks/train-puzzle-browser.cjs` 用全新存档、真实拍照与鼠标拖动，检查四档/同行者落手/存档重载/320px 与 390px；模型文字用测试替身验证宿主上下文和房间写入，不请求真实账号。

## 双人递片

「一起拼」时，把碎片中心拖到桌面下方的递片区，同行者会优先尝试这片，仍保留个人熟练度与试错率。「请 TA 递一片」让同行者把一片拖到手边，等待玩家接过；递回本身不计落位或贡献。一轮只处理一片，状态随拼图保存，换参与方式会取消待办。一起拼自动留最后一片给玩家（包括双方同时操作的情况）；明确递过去或切换看 TA 拼，同行者仍可完成。

`cooperation.mjs` 共用待办、动作目标、贡献与聊天事实。聊天沿原宿主，新增合作快照，不增加模型调用。`cooperation.test.mjs` 验证真实落位、错误尝试、递片恢复和末片规则；`train-cooperation-browser.cjs` 检查真实双向拖动、房间上下文、重进读档、保存失败、小屏与并发末片。

## 取景、相册与带回庭院

拍照进入实时取景器：拖动平移、1–3×取景变焦、三分线（只在预览）、3:2照片；风景继续流动。列车底栏/拼图桌“相册”和庭院花册“旅行册”共用宿主 `TravelAlbum`，同档读取 train.photos/artworks，可预览、导出 JPEG、二次确认删除。当前未完成拼图使用的原图禁止删除；删除已完成原图清空当前桌但保留独立成品。拼成后“装框收藏”把照片、切缝和片数/地点绘成独立 JPEG，同一桌重复收藏不重复造图。再次上车保留成品。

“带回庭院”走 `world.receiveTravelArt`，按 sourceId 去重，遵守 THING_CAP；写入普通 things，recipe=travelframe。训练场景宿主写同档 garden（保留原日期物资），庭院内走实际游戏接口并保存失败回滚。图片/sourceId 经 restoreThings、donate、restoreCollection 一路保留；删除相册原图不移除庭院实体副本。屋里/收藏馆卡片显示图片，实际摆放与展览共用 makeKeepsake 三网格相框，动态贴图清理在 disposeKeepsake。不增加独立模型资产。

`album.test.mjs` 覆盖裁切/删除/去重/摆放捐赠恢复；`scripts/checks/train-album-browser.cjs` 用实际12次指针拖动完成拼图，再验导出下载、原图/成品带回、删原图不丢框、庭院实体摆放和旅行册入口。
