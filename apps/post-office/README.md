# 邮局小店

小世界第五个入口，所有角色共用文字版的 `x_stampShop`。不经过角色/房间建档，不新开存档键、外貌档或模型资源，不写主聊天或记忆。手势沿公共 `createMapGesture`：拖动平移、双指缩放、全景复位。宿主公共 Head、iframe 场景、56px 与 0.4 底安全区底栏沿列车/庭院接法。

## 共用经营与模型边界

`js/stamp-shop.js` 是唯一经营控制层，文字版 `StampDuelPage` 和 3D `ShopSession` 都发送操作。价格、加成、卡容量、限定月份、客人批次继续来自 `StampDuel`。排班只在开门前，换岗不顶掉别人，工牌必须是本人可用卡。橱窗/工牌共用 `StampShopFilters`、`sortedCards` 和 `StampThumbnails`。

控制器每次读最新档，按日期、时段、对象身份及 `rev` 校验并仅修改本次字段，通过 `commitJSONDurable` 串行落盘。失败保留旧档与现场，先重试同一操作；不接着扣钱或播放成功动作。现实日期/客人推进也走同一层，3D 停留期间会同步。半夜停止接客、撤人；跨日按原规则保留排班与漏打烊条子。空坏档、已删除角色/卡安全降级。

只有明确点击原有来访对话或打烊故事按钮才调用宿主 `stampShopChat`，沿原 `ctxFor`/`runProbe`，3D iframe 无模型接口。控制器在原档保存请求标记，同次请求单飞；结果回来后重读并合并，不能盖掉同时改的邮花、卡和装修。已生成但保存失败的结果暂存内存，重试只保存；整页重载后未确认的请求不自动再花调用。也可明确选择只关门。

`customer.meet` 保留原文字数组，另在该客人记录保存 `meetTurns`（明确 speakerId/text）、`meetCast`、`meetKey` 与 `meetSeen`。3D 仅播放这份结果，不能按最新排班猜旧说话人；旧记录缺身份仍可阅读。打烊文字保存在原 `closing`，关灯、离店不再结算。没有新增持久存储键。

## 场景与动作

`state.mjs` 投影岗位、胸前工牌、橱窗、全部装修及当前真实批次。店员与角色客人均由宿主 `CompanionFace.lookFor` 读取陪伴 `x_companion.looks[charId]`，沿 `seatLook` 补默认体型，和 TA 的一天共用同一接法。衣服、发色/花样、肤色、体型、异瞳与表情随原数据更新；不把当前选中的陪伴角色误用给所有人，不在邮局复制一份外貌档。急件红标、难缠表情只表达实际字段。

`flow.mjs` 管实际人物路径：复用现有导航器、步态、坐姿和身体避让，绕柜台/左侧展示架。客人从门口进来排队，成交后拿信离开，未成交或换批离开不拿信。批次身份是「日期|时段|客人 id」，避免跨天复用 id。新客等旧队列腾空后入店。来访角色有长凳空位才坐下；对应店员走到长凳边、按保存身份面对面说原话、再回岗。打烊先收拾、逐盏关灯、往门口离开，然后读原故事；次日可继续开门。

打开经营整页/后台时暂停，关闭继续。跨文字版往返只在 `window.StampShopScene` 暂存纯现场快照，没有新增落盘键；返回用最新存档续上已成交离店、已保存对话。刷新直接按持久事实恢复，不重发钱或生成。镜头不存档。

`view.mjs` 用现有 Three、`createRoomKit`、`createTraveler`。列车/邮局共用 `world-renderer.mjs` 设置和释放；人物离场调用公共 traveler 的实例释放，保留共享模型/衣发/表情资源缓存。切世界释放 RAF、计时器、监听、观察器、场景与 WebGL 上下文。徽章挂在实际身体骨骼，信封跟随手部挂点；缺图用卡名纸片。

## 普通客人的独立衣服

`npc-appearance.mjs` 按文字版实际 NPC/TOUGH 名称与点名买卡字段固定映射，`npc-outfits.mjs` 按身份组装服装，公共 `npc-tailoring.mjs` 负责立体版片、布料与缝制部件：独立衣身/内搭、闭合肩口的袖子、翻领/圆领、门襟与纽扣、衣袋和翻盖、裙褶、裤脚包边、皮鞋鞋底与鞋带、带扣书包及围裙背后系带。布纹/格纹/针织纹理随整片衣料，而非整面胸前纸片。躯干与裤腿绑定原骨骼，袖子沿原身体表面取皮重，所以走路和拿信仍用同一副动画；客人服装不登记到角色衣柜，也不读取/下载 `outfits/*.glb`。共用的身体、脸和发型仍用现有资源。

## 入口与验证

点实体柜台/「去柜台」沿公共 `StampNavigation` 一次性深链打开文字版，带 `back:fairy-shop` 返回这家全局店。原卡片/对局邀请也使用同一公共入口。点店员开岗位小菜单，信格墙开整页选卡，摆件/虚线框开装修页；整页沿透明 Head、一个滚动正文、原返回栏，列表/详情保留位置，拖动/缩放不产生点击。

纯测：`test/stamp-shop.test.js`（真实目录、注入 writer 的经营/失败/并发）、`test/post-office-flow.test.mjs`（路径/队列/会面/闭店）、`test/post-office-world.test.mjs`（公共 writer 投影及宿主桥）。

浏览器：`scripts/checks/post-office-phase2-browser.cjs` 验实际写入与文字往返、人物与气泡、打烊结果补存、32 件三等级、三手机宽度及手势；`scripts/checks/post-office-browser.cjs` 保留第一期空坏档/光照/删除角色/其他世界往返与释放回归。均使用干净浏览器和构造存档，阻止真实模型、记忆与外网。WebKit 旧执行器若不能写图片 Blob，仅构造图片键使用内存替身，文字档仍用真实 writer；Chrome 检查真实图片 IDB。未测试实体 iPhone。

发版前 `node scripts/build-fairy-garden.mjs` 两次确认幂等，按根版本手册走正常 ship；资源图涵盖邮局和共用 traveler/renderer，不手工改运行缓存指纹。
