# 邮局小店

小世界第五个入口，所有角色共用文字版的 `x_stampShop`。不经过角色/房间建档，不新开存档键、外貌档或模型资源，不写主聊天或记忆。手势沿公共 `createMapGesture` / `createMapOrbit`：单指360°旋转与俯仰，双指平移/缩放（0.65～24倍，可近看工牌），「全景」恢复默认角度、位置与倍率。正交平移/视锥和外墙切开复用 TA 一天的公共机制；信格墙、橱窗卡与装修标为家具，旋转不会把它们当外墙藏掉。宿主公共 Head、iframe 场景、56px 与 0.4 底安全区底栏沿列车/庭院接法。

## 共用经营与模型边界

`js/stamp-shop.js` 是唯一经营控制层，文字版 `StampDuelPage` 和 3D `ShopSession` 都发送操作。价格、加成、卡容量、限定月份、客人批次继续来自 `StampDuel`。排班只在开门前，换岗不顶掉别人，工牌必须是本人可用卡。橱窗/工牌共用 `StampShopFilters`、`sortedCards` 和 `StampThumbnails`。两种实体卡面在 view 中共用贴图装载与近看过滤，保留卡图色彩；同一工牌卡换封面或补画卡面后会即时刷新。

控制器每次读最新档，按日期、时段、对象身份及 `rev` 校验并仅修改本次字段，通过 `commitJSONDurable` 串行落盘。失败保留旧档与现场，先重试同一操作；不接着扣钱或播放成功动作。现实日期/客人推进也走同一层，3D 停留期间会同步。半夜停止接客、撤人；跨日按原规则保留排班与漏打烊条子。空坏档、已删除角色/卡安全降级。

只有明确点击原有来访对话或打烊故事按钮才调用宿主 `stampShopChat`，沿原 `ctxFor`/`runProbe`，3D iframe 无模型接口。控制器在原档保存请求标记，同次请求单飞；结果回来后重读并合并，不能盖掉同时改的邮花、卡和装修。已生成但保存失败的结果暂存内存，重试只保存；整页重载后未确认的请求不自动再花调用。也可明确选择只关门。

`customer.meet` 保留原文字数组，另在该客人记录保存 `meetTurns`（明确 speakerId/text）、`meetCast`、`meetKey` 与 `meetSeen`。3D 仅播放这份结果，不能按最新排班猜旧说话人；旧记录缺身份仍可在场景以旁白播放。打烊正文保留在原 `closing`，同次结果的 `closingTurns` 保存明确说话人/动作，`closeCast` 保存当晚岗位身份；正文与店员下班便条一同按天追加到同一档的 `closingHistory`，便条读取沿公共 `StampShopNotes`；原有便条美化挂点与今日正文直接段落层级保留。旧正文在跨天清空今日字段前迁入留底，补写和迟到到次日的打烊只归原日，不覆盖新一天。保存失败只补存；只关门不造空故事，也不抹掉已写故事。没有新增持久存储键。

## 场景与动作

`state.mjs` 投影岗位、胸前工牌、橱窗、全部装修及当前真实批次。店员与角色客人均由宿主 `CompanionFace.lookFor` 读取陪伴 `x_companion.looks[charId]`，沿 `seatLook` 补默认体型，和 TA 的一天共用同一接法。衣服、发色/花样、肤色、体型、异瞳与表情随原数据更新；不把当前选中的陪伴角色误用给所有人，不在邮局复制一份外貌档。急件红标、难缠表情只表达实际字段。

`flow.mjs` 管实际人物路径：复用现有导航器、步态和身体避让，绕柜台/左侧展示架。看店椅、来访长凳和演出就座共用 TA 的一天 furnitureSeat/深椅姿势与 traveler 后臀承托；建模和坐点读取同一份家具尺寸，翻新软垫按实际坐面加高。客人从门口进来排队，成交后拿信离开，未成交或换批离开不拿信。批次身份是「日期|时段|客人 id」，避免跨天复用 id。新客等旧队列腾空后入店。来访角色有长凳空位才坐下；对应店员等访客到位后，按实际坐姿位置找可达的近处站位，留出访客起身的位置；没有长凳也走到访客跟前。来访与打烊的转向、闲时双人交流共用 facePair；来访普通话轮没有 targetId 时用已保存的这对来访身份，逐帧维持朝向，换说话人/气泡分页/同步都不重置。普通对白和公共表情保留坐姿，不为 talk 重新走位；位置类动作仍照原句演。避让按可见坐姿位置，收势先回交谈起点，整段结束才回岗/回长凳；对方离开时清理演出姿势。来访对话和打烊共用 `playback.mjs`，把完整原文无损分成适合气泡/旁白的小段；可下一句或结束演出。打烊先在原岗位角色之间播放原话，配合同次输出的交谈、收信、看橱窗、歇脚、帮忙和收拾动作，再逐盏关灯、沿路出门。其他描写保留旁白，不猜说话人。历史重演临时借用原班角色与现有陪伴外貌，结束恢复当前现场，不结算或再生成。次日可继续开门。

打开经营整页/后台时暂停，关闭继续。跨文字版往返只在 `window.StampShopScene` 暂存纯现场快照，没有新增落盘键；返回用最新存档续上已成交离店、已保存对话。刷新直接按持久事实恢复，不重发钱或生成。镜头不存档。

`view.mjs` 用现有 Three、`createRoomKit`、`createTraveler`。列车/邮局共用 `world-renderer.mjs` 设置和释放；人物离场调用公共 traveler 的实例释放，保留共享模型/衣发/表情资源缓存。切世界释放 RAF、计时器、监听、观察器、场景与 WebGL 上下文。工牌通过公共 traveler.attachChest 随当前衣服的蒙皮、体型、换衣与身体动作一起移动。牌面保持平整，按覆盖区域内真实衣料三角形的最外侧留出3mm间距，领口、褶皱及网格点之间的凸起也不能穿过牌面；窄胸口会缩到合适大小。信封跟随手部挂点；缺图用卡名纸片。

## 留底、窗外、闲时与声音

`StampShop.history` 是唯一留底投影，文字版和3D菜单共用 `StampShopStories`。文字版按天展开完整正文，旧日期只在展开时挂载正文；3D菜单只列重演入口，生成成功直接回场景，不自动弹整页读文。来访对话可在3D主动点同一按钮生成，仍走宿主原有的一次调用；文字版也保留同一份原句。

`exterior.mjs` 用现有 `createRoomKit` 造巷子、三栋邻屋、树、路灯与信箱。后墙开真实窗洞、玻璃不投影遮挡窗景。宿主 `GameClock.sample` 提供手机本地日期/钟点，公共 `calendarEnvironment` 复用 `townEnvironment` 的色盘、光照与同一个 `weather` 加权抽取：3–5月春、6–8月夏、9–11月秋、12–2月冬。每3小时一个日期时段种子，沿已有 `x_stampPatrolSalt`，重进不重抽、不增加存储键；小镇原14天一季保持原规则。冬天晴/阴/雪/风为20/20/45/15%，其他季节按同一表支持晴/阴/雨/雾/风。树色/地面随四季，冬晨较暗、日落较早，街灯/窗口/买过的吊灯随同一光照。景观随机天气在本机生成，不请求定位或气象。雨雪与窗面雨痕复用 `createDayEnvironment`，屋顶区域遮住室内粒子，最多120个；风力影响雨线/雪花并在最终位置遮屋顶，大风时树木摇动和16条巷外风线。场景释放沿原公共机制。

闲时仅在可见前台推进，店员会绕开家具走动、看窗边/信格、面对面交接一封信，再回岗位。还有客人等时柜台留人，来访对话和打烊可打断闲逛；不临时编造角色台词或写主线记录。跨文字页现场恢复会把未完整续接的闲时动作带回岗位。

门铃只在实际进出门时响，盖章声在成功招待的存档事实进入场景时响，交接有轻纸声；读取旧档不会重放旧音。`SceneSound` 与消息提示音共用声道和 `playSynthNotes`，各场景独立静音/暂停/释放自己的声音，不改消息提醒设置。经营菜单可开关，本次会话生效，不加存储键或音频下载；首次触屏解锁声道，后台/菜单暂停不排队补响。

## 客人身份、特征与稀客

`StampDuel.FACE_IDENTITIES / FACE_FEATURES / RARE_GUESTS` 是文字生成和3D共同的唯一词表；`shopAppearance` 输出造型ID。`npcLook(c, shopRules)` 优先认有效 rareId，再认身份/特征，未知名字才回 postcard。熟客按原名字稳定组合，不随机换装；新增词只在共用词表登记造型ID，不在3D再加关键字表。客流、熟客和稀客条件/结算都保持文字版原规则。

20种身份复用原版片、原小人骨架和 `npc-tailoring`。沿用 granny/student/painter/florist/postman/child 六套；新增面包师、老师、调音师、护士、书店店员、渔夫、修表匠、摄影师、教授、快递员、厨子、邻居大叔、留学生、新婚姑娘十四套。衣服保持原身体比例与平整衣摆，短/长袖各自提供皮肤遮挡范围；帽子按当前头发贴合，眼镜与头戴配件不进入角色外貌档。

20种特征分工：草帽、雨靴、歪领/腕表、画板、布包、眼镜、裤脚夹/车铃、红围巾、肩章/制服扣、双马尾、面粉斑、耳机、西装层、深肤色/遮阳帽挂身体或头部；鸟笼、保温桶、地图、拐杖挂真实手部；猫抱在胸前、柴犬跟在脚边。`npc-features` 负责静态衣料/挂件，`npc-props` 用公共手部接触和持物挂点跟随步行与拿信，寄信时物件转到左手。可选的“看表”小动作未加，歪领和腕表已做。

八位稀客按ID：ghost旧邮差半透明/入口薄雾；rainman长风衣、黑伞在室内保持撑开；kid小个子围裙裙装、双手玻璃硬币罐；collector三件套、单片镜和放大镜；snow厚斗篷、大背包、头肩雪和一次入口雪粒；author毛衣乱发、抱稿纸；bride婚纱/头纱并小跑；cat是真三花猫。雾雪只在实际入场一次，沿现场快照年龄续接，菜单/后台暂停，不循环补播。

`animal-figure` 是三花猫/抱猫/柴犬共用的程序四足造型，没有新增GLB。`cat-visit` 让猫旁路人的队列，沿原导航走到柜台旁，再跳到实体台面高度、低头放下嘴里的同一片叶子，只冒一次“喵”，跳下离店；叶子沿同一 Three 对象交接。猫的演出不代招待、不加邮花，不改文字存档。临时动作、入口年龄和已演过的猫只放原有内存现场续接，不增加落盘键。

NPC服装/配件/小动物实例拥有各自几何材质，离场沿释放；店员和来访角色始终由 `CompanionFace` 读取原陪伴外貌。NPC不请求角色衣服模型，不加模型文件、不调模型或写记忆。

浏览验收沿 `scripts/checks/post-office-npc-browser.cjs`：`POST_OFFICE_PEOPLE=1` 拍20身份、20特征/拿信、8稀客正侧面；加 `POST_OFFICE_COMBINATIONS=1` 实际构造400组并检查几何/皮重/原模型不变。旧模式保留11套旧造型回归。`POST_OFFICE_ONLY_GUESTS=1` 走实际宿主、三宽、持物让手和角色外貌隔离；`POST_OFFICE_ONLY_CAT=1 POST_OFFICE_RECORD_CAT=1` 留猫进门到离开录像。

## 故事动作

保存的 action 值和时长统一由公共 `fairy-garden/story-actions.js` 提供给 writer 与 ESM；存档结构不变。邮局只管地点与时序，`story-motion.mjs` 复用 traveler 的真实骨骼接触来处理拍肩/递接、扫帚与拉灯绳，旧信件摆放也迁入同一公共道具工厂。挥手/伸懒腰沿 doll-life，鞠躬/欢呼/抱臂/叹气沿 emotion-pose；新增笑与点头也在公共 emotion-pose。支持12项新动作；就近坐下只选真实空座。双人动作需同场目标，否则退回交谈；单次交接保留同一个 Three 对象，先伸手再换持有人。所有动作时钟、微动作、灯光和道具所有权只在演出内存，重演不改存档、不调用模型、不写记忆。正文优先：先完成原本的故事，再沿原有语句标最贴的动作，没有贴的用 talk；清单不催多用动作，标签不反过来添改情节/动作描写或拆句。除新增标注边界与 action 清单外，其余正文规则/调用/输出处理以原函数片段哈希回归。真实生成 A/B 用 scripts/checks/post-office-prose-ab.mjs：相同虚构店况和人设，旧6项与新18项各生成多次，保留原始正文、字数/文本块/短动作句候选，再人工审读；prepare 仅备输入，不能冒称文笔验收通过。2026-11-08 已用本机既有模型完成12份真实样本并逐篇审读，完整原文与篇幅/分块变化见 docs/邮局故事正文对比-2026-11-08.md；结果只描述本次模型和构造店况。
