# 修一处毛病，就把同类的全修了（她 2026-10-23 立）

她原话：**「以后这种记一下要修就全修，不能等我一个一个页面发现问题。」**

## 事情长什么样

点输入框、键盘升起时闪出最底层那条米黄。第一次报在聊天窗，修法只挂在聊天窗上；
第二天她在购物页又截到同一个毛病。病根从来不在聊天窗——是全 App 最底下那层底色，
哪一页有输入框都会漏。她等于替我做了一遍「还有哪几页」的排查。

## 规矩

报上来一个毛病，动手前先问：**病根是这一页独有的，还是全 App 都有的？**

- 病根在公共层（根节点、底色、键盘、安全区、存档、提示词的一族说法……）→ 修在公共层，一处管全 App。
- 实在只能逐页修 → 先 grep 出**所有**同样写法的页面，一轮全改完，回话里写清改了哪几处。
- 只修了一处、别处暂时没法修 → 回话里明说「还有哪几处没修、为什么」，不许让她自己撞上。

判据一句话：**修完以后，她还能在别的页面撞见同一个毛病吗？** 能 → 没修完。

跟 `one-public-mechanism.md` 是一家：那条管「同一个形状别开第二份」，这条管「同一个毛病别只修一处」。
