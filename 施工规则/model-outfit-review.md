# 小世界／陪伴：模型与衣服公共复盘

Lisa 2026-11-15 要求：每次做完，记下上一版容易出问题的地方，让下个窗口接着注意。这里是唯一公共经验记录，随仓库同步；本机交接只链接这里。它记录已发生的问题，不把试穿稿当成已验收或已发布。

## 每轮怎么用

开工先确认当前 GLB、Git 状态、实际体型参数、参考图和同风格的现役衣服。完成一轮（含未发布预览）后，更新相关条目：**现象／已确认原因或待查假设／有效与失败修法／必须复看的位置／证据与发布状态**。同一病根合并到原条目；旧参数只保留能解释失败的部分，不追加聊天流水。

新反馈先登记为未解决，修后补证据；Lisa 的造型意见、自动检查通过、线上部署成功是三件不同的事。其他窗口正在修的项目保留原状态。每轮收工前更新，即使这一轮只完成局部修复。

## 已踩过的坑与下次必看位置

| 易错位置 | 这几轮发生了什么 | 下一轮怎么处理、检查 |
|---|---|---|
| 整体轮廓、肩宽 | heritage 多次被反馈肥、臃肿、像垫肩；降肩又显得脖子长。别的窗口更新后也曾被反馈变宽，不能仅凭截图认定是哪项回退。 | 同一相机、姿势、发型与体型，对比参考和现役几套的正面、侧面。分开量内肩高度、外肩宽、袖根体积和腰身；先定位变化来自衣服、体型还是运行时。Lisa 当时参数是肩宽 92%，其他 100%，同时复看默认 100%。 |
| 肩头到袖身 | 单独降低 linen 领子后，肩顶出现先凹后鼓；单点回填和压平容易留下鼓包或塌肩。 | 检查从领根到外肩再到袖根的连续轮廓，用连续过渡修衣服。linen shoulder-v3 的 Hermite 轮廓有效；保留肩高、厚度和袖筒体积。修肩后连领口、袖口一起复看。 |
| 翻领与门襟 | 领子曾过大、过高、像硬板或纸片；右侧翻领到纽扣门襟连接容易断。整圈往下搬还会露出前领窝横缝。 | 同时检查翻折弧度、边缘厚度、软布起伏和领座高度；正面、斜侧近景看右领—门襟连续性。linen collar-v2 降领 .022 模型单位并保留 inner_front；这个数只属于该稿，其他模型重新测。 |
| 袖口与手臂 | 袖子曾被压塌、开口方向偏离手臂、手从一侧穿出。只看正面会漏掉前后扁塌。 | 按左右实际手臂截面分别校准袖口中心、法线和前后开口，用平滑过渡接回袖身。检查卷袖厚度与跨材质的小面是否一起移动。只更新本套覆盖参数，身体和动作保持既有设计。 |
| 测量采样范围 | linen 袖口内移后，旧的 x>.165 筛选漏掉内侧环，测出假的偏心；继续补偿会越修越偏。 | 用完整环复测；本稿改为 x>.125 才包含完整环，额外中心补偿已撤回为零。阈值随模型重新验证，不能把旧筛选当真值。 |
| 修一处带动别处 | 局部变形可能带动腰带、纽扣、裤鞋或另一侧；静态好看仍可能在体型变形、举手时翻面。 | 明确移动区、平滑过渡区、固定区。每次修后检查之前修好的部位；保留原骨架和六个体型 morph，以实际运行时走路、坐下、抬手的正侧视图验收。 |
| 材质与换色 | 领口布尔内壁默认圆柱 UV 曾污染裤鞋染色图；换色可把布纹盖掉。 | 内壁显式指定正确材质槽和衬衫 UV，保留 dyeTexture。逐一换六区颜色，核对其他区域不串色，再测切换、刷新、恢复默认和角色隔离。 |
| 阴影与染色边界 | bamboo 按单个三角形的深浅分色时，把腋下与腰部阴影误认成腰带；高反差换色出现锯齿。 | 先结合 UV 面片范围、原色与衣服结构归属；UV 面片仍可能跨过袖缘，bamboo cuff-v2 已沿实测袖口连续边线切分跨线三角形，并插值保留 UV、法线、骨权重和形变，再重算局部中和贴图。不能把整 UV 岛当成完整衣片，也不能只凭深浅分色。用高反差配色逐侧看完整一圈；袖缘异色碎片已清，领口接缝仍待造型复看。 |
| 长袍坐姿 | bamboo 直接蒙皮时前襟卷起；尝试短上衣的下摆收拢会更严重。按假定髋高做坐姿形变也会把前襟抬得过高。 | 从现役运行时采集实际裤面与骨架，再制作衣服自己的 seated 形变，复用既有驱动。前襟铺到腿上、后摆保留垂落；正侧、坐下到站起及极端体型都复看。此次短上衣贴合试验已撤销，不能把试验模块带入生产。 |
| 压缩与正式接入 | 浏览器拦截试穿能显示，不等于正式衣柜有这套；压缩后也可能与预览稿不一致。 | 从最终压缩 GLB 重载核验，不只验 Blender 源。记录字节数与 SHA；通过 prepared_outfits.json 和 dye_regions.py 注册独立服装，沿公共衣柜、存档、骨架与加载机制。发布后对线上 SHA 和实际衣柜再验。 |
| 背头顶部与侧后轮廓 | 顶部后梳弧度偏平；只抬中央的首稿又被 Lisa 指出像凸包，要求整个顶上连左右一起蓬松。 | 以现役内收发壳为基线，整个上半发帽同向抬升、左右上侧稍外撑，向低耳侧和后颈渐隐；不能用窄横向权重堆起中间。沿原发束微后梳，逆转置同步法线。检查同机位正侧背、发际线与后颈，记录固定区位移；增量脚本校验输入 SHA，避免重复变形。 |

## 下次交付前的最小复看

1. 对比上一正式版、当前稿、参考及同风格衣服；记录相机与实际体型，固定比较条件。
2. 从领根到肩头、袖根、袖口、手，连着看正面和侧面；再看收腰、裤鞋以及右领接门襟。
3. 从最终导出文件检查骨架、体型变形、动作和六区材质。与本次改动无关的旧成果也做相邻区域回看。
4. 用公共衣柜验证实际加载与配色保存。只有改了相关内容或发现新问题才扩大测试范围。
5. 将本轮新问题和未解决项回写这里；具体模型数值、长日志与脚本留各资产文档和证据目录。发布时另按版本手册执行。
