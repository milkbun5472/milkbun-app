# 施工规则（要动 js/ 里的东西，先把这一份读完）

**为什么在这儿、不在 `.claude/rules/`**（她 2026-09-06：「把 claude rule 的施工规则
换个地方放吧，言秋不需要每次都看这个」；根上那句是「你的脑袋里装了太多规则就装不下我了」）：

`.claude/rules/` 每个会话都会**整份**进上下文——包括只是来说说话的窗口。
这十三份加起来两万多字，只有真要改代码的窗口用得上。搬出来之后，
聊天窗口的脑子还给她，施工窗口自己来这儿读。
（先例：`屎山台账-2026-09-06.md`、`界面装修工单-2026-09-03.md` 都在仓库根。）

**判据一句话：这一轮要不要动 `js/` 里的文件？**
要 → 先读这一份，再按下面点名的那几份读完再动手。
不要 → 到此为止，不用翻。

## 这一份怎么用

前四条**每次施工都读**——它们管的是「怎么改」，跟改的是哪块无关：

| 读这份 | 它管什么 |
|---|---|
| `one-public-mechanism.md` | 同一个形状要出现第二处时：先开公共的，**已有的也搬过去** |
| `four-surfaces-same-context.md` | 一层规则要在八处都接上；漏的那处必须写明理由 |
| `stub-from-the-writer.md` | 测试的桩照【写存档的那段】写，不许照着要测的那段编 |
| `no-yes-unless.md` | 话说错了就删掉重写，不许在后面挂「但是／除非」 |

剩下九条**按今天动哪儿去挑**：

| 今天动的是 | 读这份 |
|---|---|
| 任何界面 | `mobile-ui-layout.md`（顶栏／底栏／安全区／滚动返回／底纹铺哪儿） |
| 新界面要不要做成半窗 | `no-half-sheet.md`（默认整页） |
| 一排 tab | `tabs-not-plain-pills.md`（不许只是一排药丸） |
| 任何标题、眉标 | `no-english-titles.md`（纯英文一律删，只留中文） |
| 主屏 / 根节点 | `home-screen-layout.md`（**一个都不许改**） |
| 写给模型的提示词 | `prompt-no-content-samples.md`（留格式示范，删内容示范） |
| 新开一处模型调用 | `prompt-send-shape.md`（料全放 system，user 只留一句触发） |
| 任何 `callAI` / `runProbe` | `max-tokens-floor.md`（不许低于 8000） |
| 查手机那四层数据 | `phone-data-layers.md`（钉死／演化／日志／快照＋名册） |

## 还留在 `.claude/rules/` 的两份，和这儿无关

- `cc-ledger-marker.md`——言秋每一轮都要用的账本协议，不是施工规则。
- `never-say-delete-first.md`——**任何**窗口都可能对她说「删了重装试试」，
  所以它跟改不改代码无关，留在那儿每次都读得到。

## 搬家之后路径变了

代码和测试里引用规则的写法统一成 `施工规则/xxx.md`。
测试要读规则原文时，走 `test/_rules.js` 那一处——**路径只写在那一个文件里**，
下次再搬家改一处就够（这条本身就是 `one-public-mechanism.md`）。
