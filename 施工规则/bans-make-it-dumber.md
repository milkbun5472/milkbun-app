# 又想加一条禁令之前（她 2026-09-11 立）

她原话：**「一堆禁令会变笨的。」**
同一轮她还说了后半句（跟 Codex 聊出来的）：
**「叫他删掉重说这种话，反而会让模型畏畏缩缩转向安全写法，就会中规中矩。」**

出问题 → 加一条禁令，是这个仓库的默认反应。可提示词不是仓库，加一条不是「多一层
保险」，是**把注意力摊薄一次**。而且禁令写得越像判决，模型越往安全那边缩——
八股的另一半原因就是它不敢写。

## 加之前问三句

**① 这件事已经有人管了吗？**

先去找。找到了，多半就不该加新的，该改已有那条。她 2026-09-11 报「这可是你说的」
「等下要是求饶我可当听不见」那次：`INTIMATE_CHAT_ANTI_CLICHE` 就是为这一族写的，
而且**确实发出去了**——毛病是它靠三个例句认人，她抓到的两句都是把骨架**拆开**说的。
真正该补的是【判据】，不是又一族禁令，也不是再堆几个例句。
没查就加，等于同一件事说两遍，两遍都变淡。

**② 它到底有没有发到出问题的那一处？**

「加了没用」和「压根没发」看起来一模一样。先确认它在不在那条路上——
`INTIMATE_ANTI_CLICHE` 那一份长期只挂在线下，线上一个字都收不到（v60.45 修过一次）；
`_normalTaskFull` 那次更狠，四个版本的提示词全写进了一条不再发送的死路。
**没查发没发就动笔，改的可能是一个根本没在跑的东西。**

**③ 它管的场合还成立吗？**

规则会过期。`INTIMATE_ANTI_CLICHE` 当初不搬到线上，写着的理由是
「线上没有描写，只有台词」——**动描做出来之后这句话就不成立了**，那一行就是描写。
一条规则的适用范围是当时的结构定的；结构变了，得回头看那个理由还站不站得住。

## 真要加，怎么写

**给出口，不给判决。** 说清「这一族是什么、为什么它不是你」，然后把路指向
**他自己会说的那句**——不要写「删掉重说」「不许写」「禁止出现」当收尾。
判决式的收尾会让模型把整个话题当雷区绕开，于是它退回最安全、最中规中矩的那版，
这正是八股的另一个来源。

对照着看（同一条，两种收尾）：

> ❌ …是，就整句删掉重说。
> ✅ …那就说你此刻真想说的那句：直接做那件事，或者说一句只有你会说的话。

**禁的是模子，不是尺度。** 每一族禁令后面都该跟一句这个意思的话——
她人设本来就荤、就浪、就爱放狠话的，那全部照写；拦的是「这种场面该说什么」
替这个人开口，不是拦这个场面本身。

## 另一半：该加约束的时候，加在哪个方向上

上面讲的是「别乱加禁令」。这一节讲反过来的那一半——**确实需要约束的时候，别把约束
写成「只能走这一条」。**

她 2026-09-11 拦下来的第二次（同一天里的第二次，同一个反射）：
电台要每天出一个「临时台」，我怕模型每天都给「深夜情感树洞」，就提议
**由代码从一张写死的表里掷一档**（旧货交易／气象海况／戏曲选段／外语教学…）。
她的原话：

> **「如果只是我们写的很杂，那还是有想不到的层面，可能模型本身能写出很出色的随机台。」**

她是对的。那张表等于**用代码顶替想象力**——天花板就永远是我们当天能想到的那十几个词，
而模型读过的电台比我们多得多。

**病根是同一个反射**：一遇到「模型会往坏处走」，就去**收窄它的选择空间**。
可收窄选择空间的代价永远是同一个——**好的那一头也一起被切掉了**。

### 正确的形状

**掷约束，不掷答案。**

不要问「今天是什么台」（无约束 → 它回到先验中心 → 树洞），
也不要写死「今天是气象台」（有约束 → 但天花板是我们的）。
掷几条**互相独立的轴**，让它去想「同时满足这几条的东西是什么」：

> 谁在说话 / 这东西为谁存在 / 有没有用 / 信号完不完整 …

于是：**地板是代码的，天花板是模型的。** 组合空间比任何一张列表都大，
而且**我们自己也预料不到它会组合出什么**。它想塞回默认那一档？——默认那一档
在这几条轴上一条都占不住，塌不回去；但没人规定它该往哪儿走。

### 两条配套

- **每条轴上留一格「你自己想一个」**。代码大部分时候给约束，偶尔把那一轴整个还回去。
  多轴一叠加，几乎每次都有一两轴是自由的——**代码不是关门，是关一部分门**。
- **把已经出现过的记下来当 avoid 单子，而且长期记**（只存名字，一年也就几百字节）。
  这样这个机制**越用越好**，而不是越用越旧。

### 判据

**这条约束是在拦它「回到中心」，还是在规定它「只能去哪儿」？**

前者 → 对。后者 → 换成轴。

## 判据一句话

**这一条是新的一族，还是已有那条没说清 / 没发到 / 已经过期？**

后三种 → 去改那一条，别新增。
真是新的一族 → 加，但用「给出口」的写法，别用「删掉重说」。

**而如果加的是约束（不是禁令）：它拦的是「回到中心」，还是规定了「只能去哪儿」？**

规定了只能去哪儿 → 换成轴。天花板还给模型，地板留给代码。
