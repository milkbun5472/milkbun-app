# 电台的嗓子（tts-mouth）

跑在书房 Mac 上的一张嘴。跟 `voice-live` 那对耳朵是**对称件**：一个听、一个说。

## 为什么要它

她 2026-09-13 实测：在 **设置 → 辅助功能 → 朗读内容 → 声音 → 中文** 里装好了
「月（高音质）」，可网页这头列出来的还是只有 **Tingting / Meijia** 两把基础音色。

**iOS 把高音质那几把留给系统朗读和 Siri，不交给 Web Speech。** 所以网页里的电台
永远只能是那股机器味——除非自己架一张嘴。

这一份用 **edge-tts**（微软在线语音）：免费、不要密钥、气口是正常人。

## 跑起来

```bash
pip3 install edge-tts
VOICE_TOKEN=你自己编一个门锁 python3 tts_mouth.py
```

想换嗓子：`VOICE_NAME=zh-CN-XiaoxiaoNeural`（女声）、`zh-CN-YunjianNeural`（男声·偏沉）。
`edge-tts --list-voices | grep zh-CN` 能看全。

## 露出去

Tailscale Funnel / frp / cloudflared 随便哪个，把 `8848` 露出去，然后在 app 里填：

**设置 → API → 电台嗓子**
- 语音服务地址：`https://…/`（不带 `/say`）
- 门锁 k：跑服务时那个 `VOICE_TOKEN`
- 音色：可留空，用服务端默认

填完点「🔊 试一下嗓子」，听见「这里是本台，试音。」就通了。

## 两条接口

| 路 | 方法 | 干什么 |
|---|---|---|
| `/health?k=门锁` | GET | 在不在，默认音色是哪把 |
| `/say?k=门锁` | POST | `{"text":"…","voice":"可选","rate":"可选如 -10%"}` → 一段 mp3 |

## 说清楚的几件事

- **门锁只是挡住路过的人，不是安全边界。** 别当密码用，也别在公网上裸跑。
- **Mac 没开怎么办**：app 那头一次失败就自动退回系统音色，**不会哑掉、不会卡住**。
  电台最要紧的是一直在播，声音好不好听是第二位的。
- **不记日志**：念过的每一句都是她和他的话，不该躺在服务器日志里。
- 单次最多念 1200 字，超了截断——电台是一句一句念的，本来也用不了这么长。
